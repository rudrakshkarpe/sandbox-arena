An API for
your experiments.

Local execution through the same bounded runner used by the playground. No credentials required.
All POST requests require application/json. Cross-origin browser execution is disabled.

Submit Python202 Accepted 
curl http://127.0.0.1:8033/api/playground/runs \
  -H 'Content-Type: application/json' \
  -d '{"mode":"playground","code":"6 * 7","timeout_ms":250,"memory_mb":16,"allow_fixture":false}'

Returns a run ID. Poll the run endpoint or subscribe to its event stream to get the result. Adjust the port to match your server.


Run versioned benchmarks 
curl http://127.0.0.1:8033/api/playground/runs \
  -H 'Content-Type: application/json' \
  -d '{"mode":"benchmark","benchmark_ids":["primes-10","primes-1000"],"iterations":10,"warmups":1}'

Method Path Purpose
GET /api/playground/catalog Runtime, examples, workloads, and limits
POST /api/playground/runs Submit a bounded job
GET /api/playground/runs?limit=100&offset=0 Paginated recent history
GET /api/playground/runs/{id} Configuration, samples, and events
GET /api/playground/runs/{id}/events SSE with Last-Event-ID replay
POST /api/playground/runs/{id}/cancel Stop after the current bounded trial; send {}
GET /api/playground/runs/{id}/export Download a self-contained JSON record
The queue admits at most eight pending jobs and executes one at a time. Full queues return 429; invalid configurations return 422.
Maximums: 12,000 code characters · 50 measured trials per workload · 5 warmups · 500 ms execution budget · 32 MB allocator budget.
This local API executes code supplied by your client; it does not run or configure a live language model. An external agent can submit code through it.
