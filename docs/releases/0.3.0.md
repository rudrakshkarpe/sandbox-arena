# Sandbox Arena 0.3.0: attack-lab foundation

A local Monty attack lab with 18 versioned scenario packs, independently checked
host evidence and reproducible replay. No credentials, GPU or paid model calls
are required.

- Exercise filesystem read/write/enumeration policy, callback permissions and
  budgets, execution/memory/recursion/output limits, fresh-session state, fixture
  copies and evidence handling.
- Every pack includes a positive control, explicit assertions, fixed policy and
  a limitation statement. Guest output cannot declare its own verdict.
- Inspect live runs, per-probe checks, audit entries and measured timings in the
  minimal dark interface. Filter by category and reopen persistent history.
- Export checksummed reports; verify them offline; replay unchanged packs with
  the original configuration and parent digest. Interrupted or incomplete runs
  remain inconclusive.
- Use `scenarios`, `attack`, `verify` and `replay` from the CLI, or the local API.
- Preserve the equal-provider animated homepage and five existing benchmarks.
- CI now excludes local traces from uploaded acceptance artifacts. Release
  builds validate packaged assets and exercise the wheel outside the checkout.

## Quickstart

```bash
git clone https://github.com/rudrakshkarpe/sandbox-arena.git
cd sandbox-arena
git checkout v0.3.0
uv sync --locked
uv run sandbox-arena serve --port 8033
```

Open http://127.0.0.1:8033 and choose Scenarios. Python 3.14 is required. The wheel
and source distribution are attached with SHA-256 checksums. See the repository
README for the macOS editable-install workaround.

## Validation and scope

80 automated tests, all 12 incident acceptance cases, Ruff checks, JavaScript
syntax checks, and package resource verification passed locally. Desktop browser
checks covered execution, verification, replay and history reload. A 390-pixel
mobile execution had no horizontal overflow. CI additionally tests a clean Linux
installation and the installed wheel outside the source checkout.

This is a single-user local preview with Monty as the only implemented adapter.
The probes are authored boundary checks, not historical CVE reproductions or
security certification. Report checksums do not authenticate the execution host.
Cloud adapters, tenant isolation and an outer containment layer for exploit
research remain future work. Provider logos do not imply partnership.

The existing incident-lab commands and API remain available. Run records retain
schema 1.0; new scenario fields are additive. Scenario pack versions are separate
from the application version and unchanged at 1.0.0 in this release.
